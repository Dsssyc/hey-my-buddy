# ADR-020：本机控制台默认免登录

## 状态

已接受，依据用户 2026-09-29 的决定；2026-09-30 授权 A 批实现。本决定取代 ADR-016 中默认登录、60 秒入口与 30 天会话有效期的要求。实现验证与日常安装分别记录，安装仍须用户授权。

## 背景

单次入口在用户打开前容易过期，内嵌浏览器也可能不保留 cookie。本机同一用户的进程已经能够访问状态目录，默认登录无法隔离这类进程；浏览器跨站访问继续由 HTTP 边界约束。控制台需要一个可收藏、可直接打开的本机入口。

## 决定

1. 仅绑定数值回环地址 `127.0.0.1`。默认不要求登录，`buddy console` 打开或返回固定地址 `http://127.0.0.1:<port>/`，不需要入口票据或 cookie。免登录页面使用仅存在于服务内存的本机控制台权限，快照提供 CSRF 值；HTTP 请求仍须通过完整的来源检查。
2. 保留精确 Host 校验、写请求的精确 Origin 和 Fetch Metadata 检查、CSRF 校验、不开放 CORS、CSP、同源资源策略与凭据不进入 URL 的约束。所有页面和 API 的来源校验都在授权之前执行。免登录不扩大可调用操作，Host 的委派、续做和验收仍在 CLI 完成。
3. 设置页提供默认关闭的“需要登录”开关。开关保存在现有私有 `console-settings.json` 中，并用独立 `revision` 与 `expectedRevision` 防止多窗口覆盖，不修改 SQLite schema。设置写入成功后才切换内存状态；重启读取同一设置。
4. 开启时沿用单次入口与持久会话机制，入口有效期改为 10 分钟。开启操作为当前窗口建立登录会话，其他客户端须登录；停用时撤销所有会话和未兑换入口，下一次开启不能恢复旧权限。本机权限在切换时撤销并轮换，旧 CSRF 值不能跨越切换继续写入。
5. 服务端登录会话不按时间过期，保存的仍只有 token 哈希、公开会话 ID 与最近使用时间。浏览器 cookie 使用长效可续期存储；浏览器自身删除 cookie 后须重新登录。入口最多 16 个，会话最多 64 个，满额明确拒绝并提示在设置中撤销，绝不静默淘汰。设置页允许退出当前登录或撤销指定会话，撤销持久化后立即使其权限失效；重启不能恢复被撤销的登录。
6. 多窗口均可编辑，继续使用评价表原有修订检查与发布租约。免登录和登录两种模式都保留这些冲突检查，不能因共享本机访问权限而跳过。未知保存结果保留草稿与请求身份。

## 验证

私有目录中的真实 HTTP 测试覆盖无 cookie 读写、来源与 CSRF 拒绝、开关及重启、10 分钟票据、长期会话与显式撤销、独立窗口修订冲突。真实浏览器只访问合成预览或私有测试服务；日常控制台、服务安装与用户配置不参与验证。
