## 实现

- 新模块 `src/buddy/model_facts.py`：唯一刷新函数 `refresh_families(board, families, *, now=None, source=None)`，一次带界读取（32 MiB 上限、10 秒超时）覆盖一次调用的全部家族；解析（`parse_source`）、身份映射（`resolve_identity`）、事实提取（`extract_facts`）与写入（一个短写事务，`model_facts` 表逐家族 upsert）分离，均可注入 `source` 与 `now` 离线测试；读取边界 `family_facts` 供 L9/L11/U2 消费。
- 快照字段：`status`（`current`/`unknown`）、`facts_json`（价格、计费方式/单位、上下文长度、输出上限、发布日期、机器可读能力）、`identity_json`（解析到的 models.dev 提供方/模型 id）、`source`、`payload_sha256`、`fetched_at`、`reason`。
- 触发：仅在用户经 `user_policy_publish` 启用模型时触发——家族由无启用档位变为有启用档位的 0→1 转移，在发布事务提交后调用同一刷新函数；重复回执重放、再保存已启用档位、同家族其他档位已启用、停用与偏好/备注补丁都不触发；发布响应与回执不含刷新结果，刷新失败绝不影响已提交的发布；画像面（L11）调用同一函数即为本委派预留的边界。
- 无凭据与无后台联网：请求只有 `Accept` 与 `User-Agent` 两个头，匿名 GET `https://models.dev/api.json`，无任何授权/Cookie/token；无调度器、无周期任务；`BUDDY_MODEL_FACTS_FILE` 固定文件钩子（与 `BUDDY_MODEL_CATALOG_FILE` 同一模式）供离线与可复现使用。
- 失败沿用与未知：抓取/解析失败不写任何行（上一份原样保留）；抓取成功但无对应条目按原因记 `unknown`（`identity-unresolved`/`entry-missing`/`entry-invalid`）并带日期；无行读作 `unknown`（`never-fetched`）；显示端据此呈现未知而不是编造事实。
- 测试环境离线：`tests/python/support.py` 与 `src/buddy/checks.py` 的全部测试子进程环境固定 `BUDDY_MODEL_FACTS_FILE` 指向私有夹具路径（缺失即源不可用→沿用，绝不联网）；`_INHERITED_CHILD_KEYS` 按委派补齐 `BUDDY_ACCOUNT_SELECTION` 与 `BUDDY_SUPERVISOR_START_ID`。
