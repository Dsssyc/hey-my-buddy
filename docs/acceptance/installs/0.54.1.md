2026-10-27，开发者说“开始发版吧”之后。

- **合入 `main`：** 整合分支先快进 `socu/buddy-core`（`8ce15160`），再经 [PR #2](https://github.com/Dsssyc/hey-my-buddy/pull/2) 以合并提交合入 `main`。PR 上的 CI（`40426199390`）20 个作业全部通过。合并提交 `4de1dd94` 的树与 `8ce15160` 相同。
- **打标签之前：**
  - 从 `65502f34` 与 `4de1dd94` 各构建一次 wheel 与 sdist。wheel 的 479 个文件里 475 个相同，sdist 的 252 个里 251 个相同；不同的只是记录源码提交的 `build-info.json`、`skill.json`，以及 wheel 清单里这几个文件的哈希。
  - 发版流程会在 Ubuntu 上重新构建控制台资源，而 CI 从没在 Linux 上把新构建的资源与提交里的比对过。所以先在 `main` 上手动跑了一次只构建、不发布的发版流程（`40440635595`），它产出的两份包与本地从 `4de1dd94` 构建的逐字节相同。
