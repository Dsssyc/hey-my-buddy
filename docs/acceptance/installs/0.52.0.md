# 安装 0.52.0 的记录

2026-10-23，整合 Host。按开发者的约定，验收与安装前检查都通过的版本由 Host 直接装；这一版改了契约（0.51 → 0.52），开始之前告诉了开发者。存储形式没有变，仍是 schema 28，没有待做的升级。开发者当天说过等 C-Two 补上两处缺口再装；C-Two 0.8.2 当晚发布，本版已经改用它。

- **装的是什么：** 整合分支 `socu/integration-0.26` 的 `f59a653f`。版本 0.52.0，契约 0.52.0，schema 28。
- **内容：** 自 0.51.1（`a7862f8d`）以来合入的批次，每批由 Host 读完差异、跑过受影响的测试后验收：
  - 状态根只在边界上检查一次（`ed630097`）：所有者入口建立或修复它，其余入口只读检查；
  - 角色不再复查自己刚做过的事（`17008c67`，合并后的修正 `26e8818f`）；
  - 安装器在每个边界检查一次（`81f03a6f`）：只有 READY 条目缺失的运行时目录才会被删除；
  - 服务经一条持有的连接观察每个执行（`1e216566`），执行的活动契约去掉等待操作，契约因此升到 0.52.0（`44a5a810`）；
  - 协议边界只检查一次（`6c10ea84`）；
  - 控制台的排序拆成依据按钮与升降切换，主题跟随系统（`b56e2d0f`）；
  - Windows 的 Job、挂起启动、私有文件句柄与管道窥视改用 pywin32（`3abf34a4`）；
  - 存储回收与检查运行器的收尾经 psutil 观察进程，收进一个共用模块（`86050604`）；
  - 改用 C-Two 0.8.2：整个调度器只订阅一次连接事件，`CoreError` 从公开模块导入（`f59a653f`）。
