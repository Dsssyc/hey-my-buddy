## 内容

- **失败结论的记号在真实数据上画得出来了**（微任务“README 里的时间轴截图” `68fc6449`，合入 `37160805`）。
  - 原因：Host 结束一个微任务时，结束前的状态记进结论的 `execution_status`，随后任务与运行的状态都改为 `concluded`。时间轴只带这两个状态，控制台又只在状态为 `failed` 时画失败结论的叉圈与行名的失败色，所以这两样在真实数据上永远不出现。
  - 修法：时间轴的行加上 `conclusionStatus`，取自记下的 Host 结论（`failed`、`cancelled`、`delivered`，结束之前为 `null`）。控制台用一个共用的失败判断读它。这是 Host 面向契约的变化，所以中间号随之移动。
- **README 截图的素材**（同一个微任务）：
  - 合成预览加了一个展示场景，文字有中英文两套；
  - 一个固定条件的出图命令 `npm --prefix apps/console run screenshot:readme`；
  - 四张截图 `docs/assets/console-timeline-{en,zh}-{light,dark}.png`。

  两份 README 还没有引用它们；英文标题截断与模型名的润色另起微任务。
- **文档**：
