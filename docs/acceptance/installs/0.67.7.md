## 内容

宏任务“Router 分区与目录的卡片化”下有两个微任务，都由 Host 点名交给 Codex `openai / gpt-6.1-sol / high`。

- **“Router 分区：大标题与卡片”**，四个回合，整合为 `30ef5ca6`、`abfca57b`、`91f095d0`、`edb12857`：
  - 三项工作改为大标题；悬停提示的宽度上限加到 min(28rem, 屏宽减 2rem)。
  - 每项工作的内容是页面底色上的整宽卡片，圆角与浮层相同，圆角变量改名为 `--radius-card`。卡片里不画线，标题行 48 像素，行 44 像素。
  - 各 Router 的记录并进 Router 列表的行；记录先列读数；设置宽屏时排两列，同一列的控件对齐。
  - 列表与记录的区域不超过 6 行时随内容高，超过时保持 6 行高并显示滚动条。
- **“目录：抽屉压矮与侧栏卡片”**，一个回合，整合为 `d1310830`：
  - 抽屉右栏去掉四段名字，计入评价移到首行；上下留白收紧，左栏加宽。
  - harness 侧栏照旧是一栏，里面每个 harness 一张卡片；列表里各 harness 的节也是同样圆角的卡片；目录页的底色与 Router 分区相同。
  - 路径只在 `/` 或 `\` 处折行。

Host 另外删去了被替换的构建产物（`b258f837`、`cfb7d043`），改了参考文档（`f4fca904`、`37d4b384`），版本为 `0d990d09`。

## 验收

第一个微任务打回了三次，后两次的起因都有 Host 自己的错：

1. **第一次：**
   - 计数浮层把开合存进了浏览器，装上后以前点开过的条会自己弹出浮层；
   - 新检查往仓库里写截图；
   - 视图里有一处多余的过滤；
   - 设置字段里的滚动区挡住了英文的错误提示，Host 在 1280 至 1440 像素宽时实测到；
   - 维护两项设置的排法与读数的字重和认可的图不一致。
2. **第二次：**
   - Host 第一次要的 20 像素超出了控制台的字号表，Worker 为它在设计规则的测试里开了例外；改回 18 像素加粗，删去例外；
   - 同一列的控件没有对齐。
3. **第三次：** 为了对齐拆成左右两栏，改变了设置的阅读顺序，`hints.check.ts` 有 8 项失败；另有两条旧检查没跟上（提示宽度、用量浮层）。这几处都是 Host 跑浏览器全量才发现的，Worker 第一轮列的受影响清单漏了文件。
