- **服务端：去掉模型备注与新读取**（三个回合；整合为 `84eb6b57`、`cbb510f8`，Host 另删被替换的构建产物并改文档 `c4c4a9ff`）。新一步 38 → 39 删去 `model_notes`，连同只被备注撑着的模型，并把 `model_correspondences_no_update` 的报错改成与现在的语义一致；服务不再接受 `modelNoteChanges`，快照不再给 `modelNotes`；Router 的输入、说明与角色文本去掉备注，协议版本到 19。快照新增同型 buddy 的 `previousGroups`、最近失败的标题与 harness 的 `permissionsVerifiedVersion`。Worker 两次停下来问：换代与归并存成同一种对应关系、撤回又删掉整行，事后分不出；画像运行没有逐轮的用量与核对意见。Host 都定为不新存：旧组只写“之前的样本”，画像记录只写打回的轮数与最后一次的意见。

## 验收

- **服务端**：这一批改了删除路径，Host 在验收开始时请 `claude / anthropic / claude-opus-5-5 / high` 盲审（输入 5,825,615 个 token，其中缓存 5,825,525 个；输出 26,954 个），双方互不看结论。审查指出的几处 Host 都复核属实：浏览器检查还在找备注的输入框、`router.txt` 还说备注优先、协议版本没加一、同一个旧模型经两个名字会出现两次；打回一轮。Host 在交付的树上跑过受影响与下游的 Python 143 个文件 1,903 项、修正后 79 个文件 1,095 项、前端 109 个文件 1,340 项、浏览器全量 905 项，全部通过；在日常黑板上只读核对了新一步的删除条件：10 条备注，删 0 个模型，引用 `models` 的外键表与这一步列的一致。
- **外壳与目录**：浏览器全量有一项还在找改掉的“可用”字样，打回一轮，顺带去掉界面上的“面”与检查文件名里的批次代号。Host 第一次在 Worker 的检出里跑浏览器全量，构建删掉了三个它保留的旧产物，续接因此被 `WORKSPACE_BASE_MISMATCH` 拦下；Host 恢复那三个文件后重新续接，此后的验收都在另建的工作树里跑。最终前端 1,343 项、浏览器全量 879 项、控制台 Python 13 个文件 188 项通过。
- **Router 分区**：Worker 停下来问了两处读取缺口，由 Host 定下做法并放宽写入范围。Python 56 个文件 826 项、前端 1,338 项、浏览器全量 880 项通过。
