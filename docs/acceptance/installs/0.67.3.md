## 内容

宏任务“0.67.2 之后的控制台修改”，三个微任务一个接一个做，都由 Codex `openai / gpt-6.1-sol / high` 完成（第三个交给路由，选到的也是它）。

1. **微任务“Router 顶部导航、领域树 i 圈与标签行高度”**，三个回合，整合为 `bbce7bb1`、`bfc14381`、`24c8598e`。
   - Router 的三项工作移到分区栏下面的工具带：每项是带图标的小块，选中的一块填底色，块上不带状态；指着或聚焦一块时，在它下方显示这项工作做什么；路由需要处理时，“路由”上有与 Router 分区标签相同的橙点，原因另起一行。
   - 右侧的块头删去。区标题改为“Router 列表”“维护 buddy”“画像 buddy”；没有指定 buddy 时，buddy 区里写一次“此项工作不运行，请指定 buddy。”；维护与画像说明数据发给谁的小字，收进区标题旁的问号圈。
   - 问号圈的卡片开在问号圈下方，左缘与这一项的标签对齐，离窗口边缘至少 16 像素；点开的卡片开着时可以盖住下面的内容，直到关上（Host 在第一回合定）。
   - 领域树：名字后面的 i 圈打开详情，用 Radix 的 Popover；点行本身仍是展开与收起。自写的放置与避让代码删去。
   - 顶栏与 Buddy 分区栏从 44、48 像素降到 36 像素，评价详情两个标签的底边距从 12 像素改为 8 像素，字到下划线约 6 像素。
2. **微任务“锚在控件上的卡片都用目标卡片的展开”**，两个回合，整合为 `1430ff14`、`dc4bdeef`。
   - 共用的卡片从打开它的控件处展开：2 像素的前沿线起始与控件同宽，移动中展开到卡片全宽，只沿打开的方向裁切，左右不裁；关上时反向，减少动态效果时没有。前沿线只有目标卡片用目标的颜色，其余用 `--ink2`。
   - 目标卡片改由 Radix 放置，删去自己的测量与放置，外观与展开不变。
   - 顺带：默认模式的说明分成两段；悬停提示离窗口边缘 16 像素；Router 的记录表在 390 像素宽时于各自的区域里横向滚动，时间不折断。
3. **微任务“控制台界面文字按审定清单润色”**，一个回合，整合为 `225e179c`。
   - 按 Host 审定的清单改 151 个键，两种语言共 190 个值。例如“还没有”改“暂无”，“只看”改“仅显示”，“知道了”改“关闭”，“改名”改“重命名”，“擅长 / 不擅长”改“优势 / 不足”，“这次没读到”改为 ADR-027 定的“待确认”，“可能卡住”改“疑似停滞”，“等待模型开始作答”改“开始作答时限”。
   - 核对时发现三处原文与代码不符，一并改正：探索名额的说明（代码给的是第 N 次）、“额度被拒，已改派”（满载时同样改派，改为“提供方拒绝，已改派”）、“停止请求未提交”（实际是被服务拒绝）。

Host 另外删去了被替换的构建产物（`8fd99eda`、`5ebf6481`、`10ab25e2`），改了文档（`8eefaf6f`、`fe91ef54`、`d3bf6b48`），版本为 `16d602e4`。
