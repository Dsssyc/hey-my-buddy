## 装后发现的缺陷

装好之后，Host 发现打包进去的控制台资源比前端源码旧：删除修复给控制台的删除回复加了 `repository-missing` 这个跳过原因，却没有重新构建 `src/hey_my_buddy/console/assets`；Host 验收那一批时也没有核对构建出的资源。装上的控制台因此会把带这个原因的删除回复判为格式不对：看板上删掉了，控制台却报错。完整检查只跑前端的类型检查与单元测试，不构建；浏览器检查在构建之后跑，所以都没有拦住。修正随 0.53.1 装上；“打包的资源必须等于源码的构建”作为一道检查补进完整检查。
