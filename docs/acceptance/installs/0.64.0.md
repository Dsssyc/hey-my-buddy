# 安装 0.64.0 的记录

2026-11-06 21:28–21:29 UTC（北京时间 11-07 05:28–05:29），整合 Host。这一版改了契约，契约版本到 0.64.0：执行进程的运行契约多了只联网一档，Router 多了画像这种调用，路由输入按模型给出候选并带上画像，Router 的协议到 17；控制台的读写改为按模型。也改了存储形式，schema 36 升到 37。安装要求黑板空闲，并先做备份。从整合分支的提交 `618c9c43` 安装，开始前已告诉开发者。

## 内容

按 [Router 第四步的执行计划](../../design/adr021/router-step4-plan.md)：

- **只联网一档**（微任务“只联网一档：四个 harness 的原生落实”，Codex `gpt-6.1-sol / high`，五个回合；整合为 `f7ff2a5e`、`b1e24cb1`、`5322f470`、`9baa8ada`、`e7ed31a1`）。权限档位多了 `web`：能联网搜索与抓取网页，不给读本机文件或用户接入的其他数据（MCP、插件、连接器）的工具，也不能执行命令；只联网的运行一律新开原生会话，工作目录是空的私有目录（[ADR-021](../../decisions/021-router-buddy-planes-and-routing-evidence.md) 第 14 条）。Codex、Claude Code 与 DSH 声明强制落实；ZCode 不声明。
- **模型与对应关系的存储**（微任务“模型与对应关系的存储（schema 37）”，Codex `gpt-6.1-sol / high`，三个回合；整合为 `4a750a5b`）。黑板有了模型这一层：模型服务的名字经只追加的对应关系对应到模型，执行开始时记下当时的模型，同型 buddy 的统计、归纳与备注都按模型。存量里每个名字算一个模型，同一模型下文字相同的备注留一条（第 24 条）。
- **画像面**（微任务“画像面（服务一侧）”，Codex `gpt-6.1-sol / high`，三个回合；整合为 `c525a9eb`、`c6e83008`、`5c11348d`）。用户指定的画像 buddy 在只联网一档上为一个模型构建画像：服务校验答案的结构、链接、日期与对应关系的建议，最多打回两轮；画像只在服务对工具与停止的判定通过之后才写入；路由输入的每个模型下带上画像（第 2、11、12、13 条）。只由用户在控制台触发。
- **控制台**（微任务“控制台：画像面、对应关系与按模型的备注”，Codex `gpt-6.1-sol / high`，两个回合；整合为 `daee0ce1`、`a47890fa`，Host 另删被替换的构建产物 `7232cbe0`）。角色页加画像面，目录里每个模型显示画像、构建按钮、对应关系与按模型的备注。开发者 11-06 定这一版的界面最基本可用即可，之后看呈现的内容再重做。
- **控制台按模型读同型 buddy 的评价**（Codex `gpt-6.1-sol / high`，一个回合；整合为 `ca458609`，Host 另删被替换的构建产物 `618c9c43`）。见下面“验收”。
- 文档：执行计划（`21a57500`、`de833698`、`a16618ae`）；问询只送达正在运行的回合（`23f7e218`）；只联网一档的原生核实结果写进 ADR-021 第 14 条、harness 参考页与调研笔记（`800c7fa0`）；参考页（`b6794778`）；第 24 条：把名字对应到另一个模型也从改的那一刻起生效，读的时候不合并（开发者 11-07 定，`0f46b3d6`）；README 的安装命令（`c8d56b7c`）。

## 验收

  - Codex CLI 0.164.0：前两次探针在调用模型之前就失败了，Codex 的配置解析不认带引号名字的点号覆盖键，改为嵌套的对象（`9baa8ada`）。代码模式的 `exec` 跑的 JavaScript 没有文件、进程与模块，服务按它确切的事实形状接受它；图片生成关掉（`e7ed31a1`）。后两次调用了模型，输入 111,841 个、输出 1,077 个，输入 72,235 个、输出 1,562 个；改完之后读文件、命令、MCP 都做不到，搜索与抓取成功。

## 这一版的边界

- 画像面在日常黑板上还没有运行过：画像 buddy 要由用户在控制台指定，构建也只由用户触发。真实的画像只在私有服务上为一个模型跑过，画像 buddy 是 Codex；Claude Code 与 DSH 担任画像 buddy 没有完整跑过，它们的只联网一档只经探针核实。
- 画像面对应关系的建议、撤回与标出换代只在测试里验证过，真实画像没有给出建议。
- DSH 在这台机器上抓取不了网页（假 IP 的 DNS），只能搜索。ZCode 不声明只联网一档。
- 控制台是最基本的界面，像素只在合成预览上看过；日常控制台上的样子由开发者看。
- 只在 macOS 上验证；这一版没有推到 CI，没有在 Linux 与 Windows 上跑过。
