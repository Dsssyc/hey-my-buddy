- **`get` 的完整输出不再截断任务书**（微任务“get 完整输出不截断任务书” `2353468b`，合入 `9c94a1b4`）：服务视图给任务书全文，`taskTruncated` 恒为假；CLI 的简要 `get` 带开头 2000 个字符并如实标出截断。
