# 安装 0.56.3 的记录

2026-10-28，整合 Host。这是补丁版本：契约仍是 0.56.0，存储形式仍是 schema 31，所以不要求黑板空闲，也不做备份。从整合分支的 `4d895a13` 安装。

## 内容

**停服务时不再关闭正在用的黑板连接**（微任务“停服务时不关正在用的黑板连接” `2a8476a8`，合入 `4d974245`）。

- `Database.close()` 先拒绝新的借用，再等所有借出的连接归还，不设超时，然后才关闭连接。
- 停服务时，C-Two 的停止调用抛出的异常不再被吞掉。
- 原因：控制台的请求线程不随监听一起结束。以前停服务时若有控制台读取在途，关闭就落在这个线程正在用的连接上，CPython 的 sqlite3 会因此段错误。本机 2026-10-28 有两份这样的崩溃报告。

## 这一版的边界

- 关闭会一直等到每个借用归还。若某个线程持有连接后卡住不退出，停止就一直不结束，不会再强行关闭。
- 停止开始之后，在途的操作若还要再借一个连接，会被拒绝，这次操作失败；写事务随之回滚。
- 只在 macOS 上验证过；Linux 与 Windows 没有跑这一版。
