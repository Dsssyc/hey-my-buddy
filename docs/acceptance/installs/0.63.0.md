## 装上之后发现的问题

装好后第一次执行（13:03:18Z）就有一个 Host 的 `await` 以 `issue` 返回：`EXECUTION_UNKNOWN`，"Execution shutdown cannot be verified"。0.255 秒后服务就确认了停止。日常黑板上回查：10-28 以来 950 次执行中有 169 次在收到回执之后记过这样一条，全部很快被确认停止并清除（中位数 0.148 秒），机器越忙越常见（11-06 是 135 次里 43 次）。以前这条问题只留在事件里；有了门铃之后，正在等的 Host 会被它叫醒，并照 Host 指南告诉用户，这是误报。

原因由 Host 读源码并隔离复现过：证明会话已空需要连续两次扫描都为空，第一次扫到空时状态是 `empty`；调度器把它当成“证明不了”，立刻记下问题；下一轮扫描证明已空，问题随即清除。修复（在一次观察之内完成两次扫描，`empty` 不再离开观察层）作为 0.63.1 交给微任务“会话为空的证明在一次观察内完成”，当日装上，见 [0.63.1 的安装记录](0.63.1.md)。
