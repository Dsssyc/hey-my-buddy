# 安装 0.58.0 的记录

2026-10-31，整合 Host。这是中间版本：契约从 0.57.0 变成 0.58.0，存储形式从 schema 31 变成 32，升级走从升级下限 0.54.1 起的迁移链（冻结的 30 → 31，加上新的 31 → 32）。所以要求黑板空闲，并且做备份。开发者 10-31 发话之后，从整合分支的 `c014767e` 安装。

## 内容

- **schema 31 → 32 那一批**：存储剪枝，升级改成迁移链。见[那份记录](../schema-32/acceptance.md)。
- **采用 C-Two 0.10.0 与 0.10.1**：见 [0.10.0 的记录](../release/c-two-0100.md)、[0.10.1 的记录](../release/c-two-0101.md)。
- **停服务时不碰停在 Host 边界上的微任务**（微任务 `8197a9ae`，合入 `45f8d394`）：
  - 安装的空闲判断与服务停止共用一个定义：`blackboard/store/work.py` 的 `autonomous_tasks`；
  - 停服务时只取消下一步能自己走的排队工作，停在 Host 边界上的微任务不再经底层路径取消，也不再留下服务问题；
  - 受影响与下游的 16 个文件、159 项单进程通过。
- **服务主动回收检出与原生目录**（微任务 `a0b25868`，合入 `9fde8ec3`）：
  - 依据：ADR-002 2026-10-30 的补充，以及验收中定下的 2026-10-31 那一段；执行计划在 `docs/design/reclaim/plan.md`。
  - 已验收或已结束的微任务，它的受管检出由服务在维护循环里定期回收；`accept` 不再有 `keepCheckout`。
  - 原生目录在验收或结束满三天、停止已证实之后删除。
  - 准备到一半中止留下的空壳，与没有任务的分配，由同一个循环清掉。
- **结束微任务时释放检出占用**（微任务 `94a77342`，合入 `c014767e`）：
  - 起因：C-Two 的 Host 会话 10-31 报告，一个早已结束的只读微任务仍占着它的检出，之后在同一检出上的 `existing` 提交因此被拒；
  - 现在结束微任务时释放占用；只读的微任务结束时不封存，所以检出变过也能结束；
  - 31 → 32 以当初验收或结束的时间，释放已结束微任务遗留的占用。

## 验收

- **主动回收**，五轮：
  - Host 读完每一轮的差异。
  - 三次 Opus 独立审查（Claude Code CLI claude-opus-5-5 / high，只读）：
    - `7c28fc20`：输入约 949 万 token，几乎全部命中缓存；输出约 6.4 万。
    - `74d79105`：输入约 923 万；输出约 6.8 万。
    - `c17d239c`：输入约 1,185 万；输出约 6.7 万。

    发现只当线索，Host 在代码里核实之后才退回。
  - 退回的主要缺陷：
    - 没有任务的分配，在黑板的写事务里做 Git 检查与删除。Host 在日常黑板上只读计时，一次引用扫描约 2 秒。
    - 同时打开的锁文件随存量增长。Host 在副本上复现：可打开文件数上限为 256 时，600 个空壳一轮剩下 352 个；修好之后全部回收。
    - 维护循环会锁住运行中任务的分配，可能撞上 Worker 的封存。
    - 没有任务的分配，回收的证明与提交撤销结论相反。
    - 证明时补锁，改写了仓库。
  - 最终：合入之后完整检查单进程通过，Python 357 个文件、5,338 项（跳过 29 项），前端 1,193 项；浏览器检查 722 项通过；存储设置页的像素看过。
- **结束时释放占用**：
  - Host 复现了两次只读的结束失败，两次都没有改动黑板。
  - 退回一次：给被挡下检出做的整树指纹并不比 Git 检查省，删掉。
  - 安装前，在日常黑板上只读预演 31 → 32 的释放查询：只释放一条，没有缺时间的行。

## 这一版的边界

- **回收在 Windows 上没有验证**：放锁之后删除锁文件与目录的次序、8.3 短名下的路径规范化，要等 Windows 测试欠账那一批在测试机上跑。
- **Linux 上没有单独验证回收**：读不到 cwd 的进程那一处，只按文档与代码推断。
- **维护调用留下的原生目录仍回收不掉**，记在待办里。
- **安装演练只在 macOS 上做过。** Windows 上只跑过 C-Two 0.10.0/0.10.1 的探针与 Python 全套，有 13 个文件的测试欠账，见待办。
