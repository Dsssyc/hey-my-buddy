- **模型抽屉重排。**
  - 模型服务的状态、首次缺席的时间与并发排在顶上一行。
  - 左栏是这个模型的推理强度，宽度按内容定：每行开头是启用开关，点这一行的其余地方是选中；选中的一行的底色铺到分隔线。左栏的高度跟着右栏，强度放不下时在左栏里滚动，选中的一行保持看得见。
  - 右栏是选中的这个强度的自定义设置：四段名字、偏好、理由，以及“计入评价 N 次”。
  - “基础设施失败”不再显示。
- **harness 的信息放进右侧栏。** 每个 harness 的位置与账户依次列出，不用点开。节头只剩左端收起本节的箭头，冷却与开放重试仍在节头；原来展开里重复的冷却明细删去。1,100 像素以下，侧栏排到列表下面。指向一个 harness 的地址会聚焦它在侧栏里的标题。
