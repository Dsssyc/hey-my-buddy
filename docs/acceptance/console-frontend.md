# 控制台前端重建：Host 的记录

Claude Code Host。依据 [ADR-029](../decisions/029-console-frontend-foundation.md) 与[执行计划](../design/console-frontend.md)。这条线由本 Host 主持并动手，本文按步骤记录做了什么、亲自核对了什么、没有核对什么。每一步之后由开发者看截图验收；本文写的是 Host 自己的核对，不是开发者的验收。

## F0 打底

2026-10-11。在分支 `socu/console-frontend` 上完成，等开发者看截图。没有合入集成分支，没有安装，日常运行时不受影响。

### 做了什么

- **样式与组件（`f6dfd59c`）。** 接入 Tailwind 4 与 shadcn。旧样式表放进一个层叠层，夹在 Tailwind 的基础样式与工具类之间：还没有迁的页面保持原样，新组件的工具类又压得过旧样式表里按元素写的规则。工具类直接读 `tokens.css` 里已有的语义变量，明暗两套不变。从 shadcn 4.21.4 取了九个基础组件：按钮、复选、对话框、输入、浮层、滚动区、选择、页签、提示。危险按钮的文字改用新增的 `--on-danger`，因为深色下的危险色是浅色，承不住白字。
- **外壳与 i18n（`a72f191b`）。** 顶栏、连接中断的提示与启动页换到新基础上，文字来自 react-i18next 的两份文案（中文与英文），每个页面一个命名空间。语言跟随浏览器的语言列表：第一个中文或英文的条目决定文字，它的完整标签决定日期与数字的写法，两者都没有时用英文；没有开关。时间一律 24 小时制。页签改名为 `任务`、`伙伴`、`设置`（`Tasks`、`Buddies`、`Settings`）。所显示快照的核对时间移进顶栏，当天的只写时刻，更早的带日期，原来顶栏下面的那一行取消。浏览器标题改为 `Hey my buddy`。新增一个按状态含义分四种色调的标签组件。旧样式表删去只有旧外壳用过的 35 行。
- **浏览器检查（`31045567`）。** `npm run test:browser` 先构建，再用 Playwright 在仓库已有的合成预览（`tests/probes/objective_console_preview.py`）上跑 `apps/console/browser/` 里的检查，中文与英文、宽 1440 与窄 390 各一遍。检查断言的是事实：每一项都在它的框内、两两不重叠、文字没有被裁掉、页面不横向滚动；页面报错或浏览器控制台出现错误也算失败，内容安全策略的拒绝正是在那里报告的。先写了两条：顶栏的几何，页签上数字的提示在悬停与键盘聚焦时出现并且留在窗口内。
- 页面内部还是旧的写法与旧的用语，只有中文；这是 F1 的工作。

## F1 第一步：打底改到设计上

2026-10-11，Host 自己做。分支 `socu/console-frontend`，没有合入整合分支，没有安装。

### 做了什么

- `tokens.css` 换成设计稿的那一套颜色，名字也用稿里的（纸、面、墨三档、线两档，进行中、等人接手、失败、记录，以及顶栏自己的几种）。Tailwind 的主题映射随之改写：生成的组件用的那组名字指向它，另加设计自己的一组。

- 圆角：控件与浮层 4px，标签 2px。
- 顶栏照稿重做：明暗两种主题下都是标志的墨色，标志换成顶栏自己的配色，当前页签下是一条绿线，等待 Host 的数目是浅橙底，右端只写时刻，它是什么时刻在悬停时与对读屏说明。

## F1 第二步：Buddy 页的导航（B0 的第一部分）

### 做了什么

- Buddy 页有了自己的导航，照稿放在页面顶部并贯通左右：两个分区"目录"与"角色"，目录打开时下面是"模型"与"Harness"的切换。三个视图各有地址：`#buddies/models`、`#buddies/harness`、`#buddies/roles`，后面可以跟一个目标；`#buddies` 之下别的地址一律打开模型。原来的 `#buddies/router` 不再有效，没有留转向。

## F1 第三步：Buddy 页的模型一项（B1、B2 与 B0 余下的部分）

2026-10-11，Host 自己做。分支 `socu/console-frontend`，没有合入整合分支，没有安装。

### 起因

上一步做完之后，Host 把"新的导航套着旧内容"的截图当作进展发给了开发者，开发者指出它与认可过的方向稿完全不一致。他说得对：那一步新做的只有顶上的导航，下面整页还是旧组件；连新做的那一条也与稿不同，稿里表的切换与搜索、筛选在同一行，实现里它单独占了一行。Host 因此改了顺序：模型一项由 Host 照稿整页做出来，和稿并排看过之后再给开发者看，不再拿新旧混搭的中间状态当进展。

对照时还发现，入库的 `buddies.html` 自己已经被后来加进 `base.css` 的规则画坏了（见静态稿的说明），开发者认可的是更早的一张截图。稿已修好，修好之后的样子与那张截图一致。

### 做了什么

- 模型一项照稿重做，代码在 `src/buddies/` 之下：`models.ts` 算出表的内容（筛选、分组、排序、默认收起、未保存的标记、原因的写法），`ModelsTable.tsx` 画表，`ModelPane.tsx` 画右栏，`ModelsView.tsx` 是工具栏与两者的容器。原来的列表、家族详情（`FamilyDetail.tsx`）与更新记录（`EvaluationHistory.tsx`）删除，连同旧样式表里只有它们在用的 89 处选择器，以及没有了调用方的几个显示函数。
