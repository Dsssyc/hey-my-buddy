# 控制台前端重建：Host 的记录

Claude Code Host。依据 [ADR-029](../decisions/029-console-frontend-foundation.md) 与[执行计划](../design/console-frontend.md)。这条线由本 Host 主持并动手，本文按步骤记录做了什么、亲自核对了什么、没有核对什么。每一步之后由用户看截图验收；本文写的是 Host 自己的核对，不是用户的验收。

## F0 打底

2026-10-11。在分支 `socu/console-frontend` 上完成，等用户看截图。没有合入集成分支，没有安装，日常运行时不受影响。

### 做了什么

- **样式与组件（`f6dfd59c`）。** 接入 Tailwind 4 与 shadcn。旧样式表放进一个层叠层，夹在 Tailwind 的基础样式与工具类之间：还没有迁的页面保持原样，新组件的工具类又压得过旧样式表里按元素写的规则。工具类直接读 `tokens.css` 里已有的语义变量，明暗两套不变。从 shadcn 4.21.4 取了九个基础组件：按钮、复选、对话框、输入、浮层、滚动区、选择、页签、提示。危险按钮的文字改用新增的 `--on-danger`，因为深色下的危险色是浅色，承不住白字。
- **外壳与 i18n（`a72f191b`）。** 顶栏、连接中断的提示与启动页换到新基础上，文字来自 react-i18next 的两份文案（中文与英文），每个页面一个命名空间。语言跟随浏览器的语言列表：第一个中文或英文的条目决定文字，它的完整标签决定日期与数字的写法，两者都没有时用英文；没有开关。时间一律 24 小时制。页签改名为 `任务`、`伙伴`、`设置`（`Tasks`、`Buddies`、`Settings`）。所显示快照的核对时间移进顶栏，当天的只写时刻，更早的带日期，原来顶栏下面的那一行取消。浏览器标题改为 `Hey my buddy`。新增一个按状态含义分四种色调的标签组件。旧样式表删去只有旧外壳用过的 35 行。
- **浏览器检查（`31045567`）。** `npm run test:browser` 先构建，再用 Playwright 在仓库已有的合成预览（`tests/probes/objective_console_preview.py`）上跑 `apps/console/browser/` 里的检查，中文与英文、宽 1440 与窄 390 各一遍。检查断言的是事实：每一项都在它的框内、两两不重叠、文字没有被裁掉、页面不横向滚动；页面报错或浏览器控制台出现错误也算失败，内容安全策略的拒绝正是在那里报告的。先写了两条：顶栏的几何，页签上数字的提示在悬停与键盘聚焦时出现并且留在窗口内。
- 页面内部还是旧的写法与旧的用语，只有中文；这是 F1 的工作。

### 核对

- 类型检查通过。前端全量 67 个文件、961 项通过；此前是 66 个文件、958 项，新增的 3 项是语言选择。因页签改名与顶栏变动而重写断言的有 19 项。
- 浏览器检查 8 项通过（两条检查 × 两种语言 × 两种宽度），Chromium headless shell（Playwright 1.64.0），macOS。
- 变异。浏览器检查三处：窄屏时不隐藏核对时间前面的文字、让导航滑到品牌标志下面、把页签压进过窄的框，三处都被拦下，第一处只在英文窄屏失败，与事先的估算一致。单元测试六处：页签不再说明数字的含义、更早的读取只显示时刻、语言不看浏览器、不设置文档语言、未保存的标记没有文字、顶栏不说连接中断。前五处被拦下；第六处第一次没有被拦下，原因是"连接中断"在两个分支里各写了一遍，测试只碰到其中一个，于是把它提成一处，再变异就被拦下了。
- 构建可复现：同一份源码构建两次，产物的 SHA-256 相同。提交的产物就是这份源码的构建结果。
- 仓库卫生测试 5 项通过，包括新产物与新文件里没有本机路径。
- 像素：三个页面，中文与英文、明与暗、宽 1440 与窄 390，共拍了 24 张截图，Host 看了其中 6 张，两种语言、明暗与宽窄都在其中。另在真实的控制台服务（合成看板上的私有预览）里看过一次，那一次浏览器的语言是英文。
- 内容安全策略没有改动。合成预览发出的策略与控制台服务的是同一个字符串；浏览器检查在它之下打开了提示浮层（Radix 用内联样式定位），没有任何拒绝。

### 没有核对的

- Windows 与其他浏览器没有跑过；浏览器检查只在 macOS 上的 Chromium 里跑过。
- Linux 上没有跑过。那里默认没有中文字体，中文的几何检查要先装字体才有意义；发布流程接入这项检查时处理。
- 读屏软件没有试过。
- 合成预览不提供 `/api/runtime-version`，设置页在预览里因此显示"无法读取版本"，浏览器控制台有一条 404。顶栏的检查不经过设置页；设置页迁移时要先给预览补上这个接口。
- 中文界面只在 Playwright 的截图里看过，没有在真实的控制台服务里看过。
