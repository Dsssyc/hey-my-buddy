## Delivered behavior

The three primary pages are top navigation tabs named `委派记录`, `模型卡片` and `路由配置`; the old navigation sidebar and large repeated statistics strip are removed. Desktop list/detail panes use the available viewport height and a keyboard/pointer-adjustable divider. Narrow windows show one pane with a back button. Detail sections use tabs, pending decisions stay visible above them, and final review/publication controls remain outside long content. Read-only assessments are text/list content, not large empty input boxes.

Model families are keyed by harness, provider and model. The actual catalog shape of four DSH models with four efforts each and two ZCode models with three efforts each produces six list entries from 22 profiles. Effort selection retains independent profile IDs, cards, preferences and evidence. Drafts and observations remain scoped to their selected configuration. Main-tab switches retain mounted view state and scroll position; task input drafts are scoped to their run. In-memory drafts do not persist through reloads.

Delegation history defaults to main governed goals, groups records by original project identity, and exposes original/current Host and the resolved executor. Helpers and internal computations are reachable through the owning goal or an explicit inclusion switch. The list loads 50 records per request, uses a stable keyset cursor, supports server-side filters and a keyboard-accessible load-more button, and preserves the reading anchor when earlier groups gain rows. New records generate a notice under the current filters instead of being inserted into the current list. The first record after an empty read is also announced.

The read-only `delegation` projection comes from persisted workflow and repository facts. Original Host attribution is recorded in existing admission events, and takeover events preserve the prior Host and generation. Deep helper creation records the Host that actually authorized the proxy request. Historical missing sources stay unknown. The current Host is the complete goal's root controller; the record's own control generation remains separate audit information. These additions do not grant authority or change cancellation/retry rules. Review filtering verifies all owned descendant and router shutdown evidence before the SQL page limit.
