## 完整检查暴露并修复的一个搬动缺陷

首轮完整检查（`<worktree>/tmp/adr025-step0/test-move/checks-full.log`，保留）Python 侧 157/158 文件通过：唯一失败 `blackboard.tasks.test_parallel_dispatch` 的 `test_decision_completes_on_the_pool_with_a_free_total_slot` 得到 `needs-host` 而非 `queued`。归因是纯路径缺陷：`readonly_bootstrap_path()` 给独立 daemon 子进程构造的 `PYTHONPATH` 原用 `Path(__file__).parent`（旧布局下恰为 tests/python 根），机械平移后变成模块自身目录 `blackboard/tasks/`，子进程 `sitecustomize.py` 里的 `from protocol.fixtures.mock_readonly import install` 因此失配，只读宿主 fixture 不再安装，决策评估找不到可用宿主。修复把该项显式指回 tests/python（`parents[2]`），同文件对 src 的引用继续用 `parents[4]`；这是本文件 942 行 sitecustomize 脚本的导入根，不是行为或断言变化。用检查运行器同款子环境焦点重跑该模块：27 用例全过、退出 0（`<worktree>/tmp/adr025-step0/test-move/focused-parallel-dispatch.log`）。随后全库专项扫描 `PYTHONPATH`/`sitecustomize` 同类构造（`test_dsh_session_storage`、`test_rpc_config`、`test_no_tool_codex` 等均以 `ROOT`/`SOURCE` 常量解析，平移后已验证正确），无第二处同类缺陷。
