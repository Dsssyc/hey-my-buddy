# L6 ADR-021 ZCode 只读回合

工作分支 socu/adr021-logic-stage2，设计见 [第二阶段计划](../design/adr021-logic-stage2.md)。ZCode 使用原生 plan、Read/Glob/Grep、禁 MCP/offPeak/dynamic/title 的受限根回合，复用公共分类与黑板发布判定。免费资格只读实际命令的公开 bundle，核对限定词法/绑定/完整模板与真实 schema/元数据，缓存按路径/dev/ino/size/mtime/ctime；不运行模型、版本探测或凭据读取，不绑定版本或证书。

Host 读取固定 A5 成果并亲自跑 99 项，修复与 A6 合并后 110 项静态/协议通过；Astra high 的 26 项 scope 测试与 24754 次反向查找等价复核通过，箭头绑定移除变异检出 4 项断言。公开 bundle 正常对照保留，扫描性能从约 190 秒恢复到合并测试约 17 秒。B 的 partial 固定 110 项通过，Host 完成环境/有界读取/缓存/错误 EOF/畸形事实/最终取消收据后 120 项相关检查通过，全部使用私有模拟并回收测试根。

B Worker 因完成工具后又调用工具而 duplicate-finish 失败，原生进程实际停止，partial 没有标为验收；Host 保留固定补丁、独立审查、完成修正，失败结论记录后立即回收检出。A/A2/A3/A4 的资格证明均曾被独立反例审查拒绝并记录、回收，修复没有追加到已发任务；最终拆成词法 A5、Host 证明消费者 A6 和 controller B。原语法/停止/预算/工具失败情形保留，未知语法失败关闭；Source 不重做原生工具或 JavaScript 执行器。

原生未验证。用户批准的首个 ZCode probe（GLM-5.3-Flash/max，brief 60 秒/8 工具/最多一次纠正）在模型输入前因临时目录过长导致 Unix socket EINVAL 而退出：modelStarted=false、工具调用 0、冻结输入未改、实际进程组与框架私有根回收均确认。未声称成功或自动重试；探针根已改为框架创建的短临时路径，新的冻结包已准备，等待单独批准。DSH 检查仍没有批准。本阶段没有安装、修改用户配置、登录、读取凭据文件或迁移日常数据。

偏离与选择：使用受支持的静态结构子集，无法证明的绑定/控制流明确不合格；不以零工具结果或自述推断原生生效。无 selected 命令的资格拒绝，避免默认文件为未知 discovery 结果背书；独立 probe 显式指定已确认的公开 CLI。Native 准备/格式纠正/关闭/EOF 与实际 owned-group 停止各自留事实；错误也 drain 全部帧，最初失败码不丢，最终取消或非零退出的收据不标完整。短路径修正属于探针运行位置，不改变已经批准包的任务或预算；首个一次执行标记仍保留。
