# L6 ADR-021 移出第二阶段

用户于 2026-10-03 叫停 DSH/ZCode 的独立只读回合与 ZCode 安装包静态核对，最新 ADR 第 4 条改为复用 Worker 执行载体，新 L6 另起阶段先设计。本阶段移除 DSH Node 桥接/Python controller、ZCode 受限协议/controller 接线、zcode_static_contract 与专属 fixture/tests；完整实现和过程计划在 socu/adr021-review-carrier-reference（15be750）备查。L4、L5 及已验收的四个事件投影保留，不把移出的工作当交付。

原生未通过。ZCode 第一包因长 Unix socket 路径在模型前失败（工具 0）；随后三次进入模型，分别在只读 lifecycle metadata（21.736 秒、23.989 秒）和未知 canonical event（22.366 秒）失败。最后一次已观察真实 Read start/end，但没有完整可采纳答案。DSH 两次模型前失败，见 L5。所有已执行检查输入未变、停止与框架回收确认；停止指令到达时没有原生检查运行，已准备的 DSH 第三包/ZCode 第五包未执行，此后不再发起检查。

移出原因是架构方向改变：为两个 harness 建立专用 Router 通道并从安装包静态证明工具限制，复刻了既有 Worker 载体的启动、事件与生命周期，也把资格变为证明厂商代码。静态模块经历多轮反例修复，真实检查仍未完整通过。历史代码、测试和失败证据保留备查，今后不沿此方向继续；新 L6 将设计冻结副本上的只读 Worker、结束后未改动核对、结构化答案和 Worker 事件投影。本阶段资格如实返回 readonly-worker-carrier-unimplemented。
