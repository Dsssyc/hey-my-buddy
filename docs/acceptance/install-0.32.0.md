# 安装 0.32.0 的记录

2026-10-13，整合 Host。用户为这一次安装明确授权，并批准了装后的两次 DSH 调用。装的是整合分支的 `3a2ea7f9`，版本 0.32.0；存储的 schema 不变，仍是 18，没有迁移。带上的是 Worker 权限档位的第 4 到 6 步与续接时换档的规则（[验收记录](worker-permission-levels-host-review.md)）。日常环境此前是 [0.31.0](install-0.31.0.md)。

## 安装之前

- 最终的完整检查通过，记在验收记录里。
- 备份预检通过，没有被拒绝或跳过的项；日常服务状态正常；没有排队或在跑的工作，没有未结束的执行。
- 记下了 133 个 buddy 的标识、启用与可用状态（启用 11，可用 117），用来与装后比对。
- 看板上有一个别的 Host 的 DSH 微任务停在已交付、未验收，它最后一个回合是只读，在 0.30.0 之下创建。那时 DSH 的只读落在可写的预设上，而 DSH 的会话沿用创建时的预设；装后如果以只读续接它，档位没有变，会沿用原来的会话，记录上写的却是强制。只有这一个微任务受影响，没有处理，已告诉用户：验收或结束它就没有了。

## 安装

从 `3a2ea7f9` 构建 skill，运行它的 `scripts/buddy install`，用时 4 分 15 秒，退出码 0。启动安装的那条命令用的是原来的服务进程自己的环境，只取白名单里的变量，并去掉了上一次安装留在搜索路径最前面的那一项；新的服务因此没有带上 Host 会话里的代理变量。安装报告：skill 更新为 0.32.0；升级前的备份已校验（schema 18，171 MB，13,772 个文件）；保留数据的指纹一致，没有源码泄漏，没有回滚；清掉了一份旧的运行时。

## 安装之后

- 服务状态正常，契约 0.32.0，schema 18，完整性检查通过，外键没有违例；新的服务进程与 7 个 Worker 起来了，没有遗留的旧进程；服务的环境里没有代理变量。
- 四个 harness 都是就绪（DSH 0.1.5-rc.1、ZCode 0.16.9、Codex 0.162.1、Claude Code 2.1.284）。Host 触发一次不调用模型的发现之后，133 个 buddy 的标识、启用与可用状态同装前完全相同。可用的 buddy 都带上了三档的能力字符串：Claude Code 49 个、Codex 44 个、DSH 16 个、ZCode 12 个；不可用的 12 个 ZCode buddy 属于用户的 ZCode 里已经不存在的两个供应方，目录里读不到它们，能力字符串没有重写，仍是只读与写检出。
- 装上的 skill 是从 `3a2ea7f9` 构建的 0.32.0，Claude Code 的链接完好。
- **真实的回合，2 次，DSH 的 deepseek-flash / max，经装好的服务，同一个微任务。**

| 回合 | 档位 | 续接方式 | 回合里发生了什么 |
| --- | --- | --- | --- |
| 1 | 写检出 | 初次 | 六条命令逐条运行，没有一条被回绝或要批准：普通的命令、命令前面带环境变量赋值的写法、经 `env` 的同一条命令、带重定向的复合命令；检出里的两个文件写成了 |

第二个回合核对了“换档的回合经装好的服务重建会话”这一整条。第一个回合顺带量了那几种命令写法在 DSH 的写检出一档下的表现，用来与 Claude Code 对照（[待办](../design/backlog.md)）。这个微任务以不需要合入结束。

## 装后另做的一次核对：换 Host

装前记下的那个别的 Host 的微任务，核对之后发现并没有被落下：它的 Host 当时就用结论结束了它，写明不接受的理由，检出也已回收；只是状态仍是已交付，读出来的等待原因仍说等最后的确认（记进了待办）。用户让整合 Host 接手它，顺便看换 Host 走不走得通。在日常服务上做了：用旧的控制文件调用换 Host，成功，代数由 1 变 2，返回新的控制文件；此后用旧的控制文件再换一次、再写结论，都被拒绝为代数已过期；同一条换 Host 的命令重放，得到同一份回执。没有给它打上验收：已有结论的微任务按设计不能再验收，结论说的是那份分析有虚构的内容。

## 没有核对的与留下的

- Claude Code 与 ZCode 经装好的服务的真实回合没有做；它们的三档是装之前在同样的源码上经角色控制器量的。那几种命令写法在 Codex 与 ZCode 上没有专门量。
- 服务的搜索路径第一项仍是安装时构建目录里的虚拟环境，是待办里已有的一条；这一次没有让旧的那一项累积下来。
- 临时目录下的测试残留（357 项）装的时候没有清，当时有别的会话的微任务在跑；随后核对它们都是早先四个微任务留下的、最年轻的也有近两小时、没有进程在用，按用户的话清掉了。
- 16 个不可用的 buddy 与运行时目录里因为格式不认识被跳过的旧安装锁文件（这次 56 个），同上一次。
