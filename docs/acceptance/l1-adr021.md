# ADR-021 L1 提交契约 0.28.0

范围为 [ADR-021](../decisions/021-router-buddy-planes-and-routing-evidence.md) 第 5、17 条及工作分解 L1 的整个提交契约：拒绝 `spec` 嵌套、`executionWorkspace.cwd`/`integrator`、`routingPreferences`（含 helper 继承）、`routingMode` 与 `allowRoutingFallback`；coding buddy 四元组全有或全无，部分字段拒绝并提示三种表达；完整 buddy 直接委派，无 buddy 由 Router，唯一合法候选由程序直接选定。实施分支 `socu/adr021-l1-submit`，基线 `004f805`；源码和契约一次提至 0.28.0，schema 仍为 15。本轮未推送、未安装、未改用户配置或日常看板，未做任何付费原生检查。

实现集中在 `src/buddy/schemas.py`：`SUBMIT_FIELDS` 去掉三个路由输入，`WORKFLOW_SUBMIT_FIELDS`/`WORKFLOW_HELPER_FIELDS` 去掉嵌套 `spec` 与 `inheritRoutingPreferences`；`normalize_execution_workspace` 拒绝两个重复字段，提交与 helper 的规范化改为从顶层 `cwd` 与提交 Host 内部推导这两个字段（manifest 存储字段名不变）；`normalize_workflow_spec` 增加四元组全有或全无校验，`command`/`external` 作为最小特例只接受 `adapter`（加 `argv`），同时带 provider/model/effort 即拒绝。每种被撤拼写都有点名的 `INVALID_ARGUMENT` 信息：嵌套 `spec` 指回平铺形式，`routingPreferences`/`routingMode`/`allowRoutingFallback` 提示 ADR 第 5 条的三种表达，`inheritRoutingPreferences` 说明任务偏好已不存在、无可继承。`selection_policy` 删除 taskPreference 槽位（`policyCheck` 只剩 `hardConstraints` 与 `userPreference`，用户 pin/prefer/exclude 规则原样保留）；`decision.py`/`workflow.py` 移除偏好读取、继承与 `preferenceOutcome` 视图字段，事件载荷不再携带偏好；`router.py` 提示词版本 10 → 11 并从输入与指令中删除任务偏好。内部路由的模式/回退机制（`router.resolve`、`configuration.defaultRoutingMode`、review→fast 回退）未动，属 L4。

保留的不变量均有测试覆盖：`requestId` 幂等（重复提交返回同一 run）、控制文件所有权与 owner fencing（takeover/late-result 用例未改）、有界 `await`、`configurationLocked`（完整四元组加锁后不兼容的 Host 覆盖仍为 `CONFIGURATION_CONFLICT`）、helper/continuation 既有授权规则（`workflow_routing` 的 takeover、取消、targetRunId、helper 停止证据用例只换了候选收窄方式）。
