## 实现事实

续接路径：`run()` 以 `_continuation_of` 读取请求续接；仅受管 Worker 载体在 `native-session` 模式先核对任务共享 native 根下的私有 goal binding（task/session/cwd/configuration，与 ZCode 同构的 sha256 文件名、strict JSON 读写），缺失或异配即 `native-resume-unavailable` 失败且不启动进程；随后经现有 `AcpClient.resume_session` 发送公开 `session/resume`，会话身份的证据来源是本次请求（响应按 Host 核对无可回读 ID，不虚构字段；若厂商回显异号 ID 立即 `wrong-native-session` 失败）。恢复应答返回后、本回合 prompt 前清空泵内重放历史（计数保留为 bootstrapUpdates 事实，不进入本回合工具/模型/回执/活动事实），并冻结目标会话的既有记录（逐行 sha256、顺序与内容）。初始与重构仍走 `session/new`，fast/review 拒绝 native-session（BoardError），行为不变。

存储布局：Worker 运行的 rollout 钉到传入 native 根的 `sessions/` 下（`session-persistence-jsonl` 行），DSH_HOME、acp profile、启动补丁、frame 日志与本次凭据控制材料全部移入 invocation 根，launch 的 private_root 与路径校验随之为 invocation 根；发现与无工具快路保持各自 native 根内私有 DSH_HOME 与其 sessions 钉（V-R2 布局断言见 test_native_resume 与 test_dsh_session_storage 的 StorageSplitTests）。settings/credentials 仍按原路径由 DSH 读取，未迁移未读内容；`native_environment` 的 HOME/locale/代理规则、三档工具范围与两个按字面行名持续关闭的行（session-title-llm、session-telemetry-otel）不变。`session_facts` 的存储归属按根的真实落位判定：恰为 private_dirs 的任务共享 native 根（`<state>/harnesses/<adapter>/goals/<sha256(task_id)>/native`）报 task-shared-sessions/buddy-goal，其余根（尝试私有根、快路与评审根）报 attempt-private-sessions/buddy-attempt；落位是目录事实，不是厂商证明，尝试根绝不误报 goal。

用量：唯一读实现移入 `session_records.py`（未复制第二套，`native_run` 仅再导出 `session_record_facts`，签名从 dsh_home 改为 sessions 根，唯一生产调用方随迁）。初始/重构回合沿用整文件口径；恢复回合用 `resumed_session_record_facts`：冻结前缀逐字节仍在同文件同序、匹配文件集合不变、追加行不得重复冻结行，只折叠可证明的追加段；缺根、集合变化、前缀重写、缩短、重复重放、基线不可读均以具体 reason 保持未知（usage/旧 assistant/旧 failure/旧 model 均不报），截断则保留明确部分为 partial；不累计相减。复用现有 `_RecordStream`/zstandard 流式限额与 usage 归一化。"匹配"与"读取可靠性"分开：合法 v3 头命名其他会话的记录是确认外来，整个跳过——不进 baseline、不降低可靠、其用量绝不折叠；无合法头可归属的候选（空、损坏、读到头之前触界）无法归属任何会话，保持不可靠的诚实未知；目标文件自身触界仍不可靠。

绑定与结果：完整原生回合（status ok）、已核验 provenance（关闭确认后生成）、正确会话绑定与真实 native gone（shutdownConfirmed）四者齐备才写/保持 goal binding（新号 exclusive 写入，恢复号核对等值），`RunResult.continuation` 用既有 `ContinuationFacts(resumable=True)`，其余情况为 None；两层停止与 `validate_turn_provenance` 既有核对保留，provenance 校验新增接受同号 `native-session`，重构仍必须新号。
