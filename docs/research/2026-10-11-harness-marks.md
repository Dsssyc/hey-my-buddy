# 调研：harness 的标志从哪里来，受什么约束

日期：2026-10-11。调研人：Claude Code Host，应开发者的要求。

## 问题

控制台的 Buddy 页改为按 harness 分节之后，要不要在每个 harness 的名字前放它的标志；标志的图形从哪里取才不算照搬别人的东西；商标上有什么约束。

## 看了什么

- 两次网页检索，读的是检索工具给出的摘要：一次找 AI 品牌图标的开源图标库，一次找 OpenAI 与 Anthropic 关于第三方使用其商标的规范。两家的规范页没有通读，下面关于规范的话都来自摘要。
- npm 登记处上两个包的元数据（许可、体积、依赖），经 `npm view` 读取。
- 把其中的静态图标包装到一个临时目录，看了文件清单与四个图标文件的开头。没有读图标库的源码与它的仓库；没有找到它自己关于商标的说明。
- DeepSeek 与 Z.ai 有没有商标使用规范，没有查。

## 看到的事实

- **有一个 MIT 许可的 AI 品牌图标库，分成几个包。** 带 React 组件的包 `@lobehub/icons`（5.23.0）解开后约 9.5 MB，要求宿主装有一套界面组件库（`antd` 6 与它自家的界面库）；只为几个图标引入它，代价是整套别人的界面库。静态图标包 `@lobehub/icons-static-svg`（1.95.1）解开后约 2.4 MB，952 个文件，没有任何依赖，里面是 SVG 文件。
- **静态包里有我们四个 harness 的图形。** `codex`、`claudecode`、`deepseek`、`zai` 各有单色与带字的画法，前三个另有彩色的画法；单色的画法随文字颜色着色。另有 `openai`、`anthropic`、`claude`、`zhipu` 等。
- **许可只管包，不管商标。** MIT 许可的是图标库的代码与打包；每个图形是各自公司的商标，怎样使用由商标权人的规范决定。
- **两家规范的口径不同（来自摘要）。** OpenAI 的品牌规范面向合作方、开发者等第三方，允许按规范使用，禁止改动图形、禁止把它并入自己的品牌，联合品牌的材料要双方批准。Anthropic 的商标规范写的是只能按它明确许可的方式、在它事先批准的材料里使用，不得改动颜色、字体与比例，许可可以随时撤回。

## 取了什么，没取什么

开发者于 2026-10-11 决定用真标志，理由是项目不盈利、风险不大。Host 的看法记在这里：商标上起作用的不是盈利与否，而是只用来指明"这是哪个产品"、不改动图形、不让人以为得到了对方的认可；对 Anthropic 的标志，按它的规范这仍然算不上明确获准，是开发者知情之后接受的剩余风险。

- **取：** 以依赖的方式引入静态图标包，只引用用到的那几个文件；标志只出现在 harness 的名字旁，用来指明它是哪个 harness；用包里现成的单色画法，不改图形；在说明里写明这些标志属于各自的权利人，本项目与它们没有从属或认可关系。
- **没取：** 带 React 组件的那个包，因为它要带进一整套界面库；彩色的画法，因为控制台里每种颜色只有一个含义；提供方与模型的标志，现在只在 harness 这一级放。

## 时效

静态图标包换了许可或去掉了其中某个图形；某一家修改了商标规范，或对这种用法提出异议；增加新的 harness，或决定在提供方、模型那一级也放标志。出现其中任何一条，另写一份新的记录。
