# 会话视图怎样显示得像一段会话：现成的展示组件

2026-10-20，整合 Host。

## 问题

开发者看了控制台里微任务的会话，觉得太难看：每次工具调用都是一块展开的区块，里面再套三层折叠，消息和工具调用一样重，一个回合几十块堆在一起。开发者想要会话式的体验，以 Claude Code app 的层次为主，不必照搬哪一家。这份记录查的是：有没有现成的展示组件能给出这种层次，为 [ADR-024](../decisions/024-console-session-view.md) 的改写服务。

## 看了什么

- **AI Elements 的厂商文档**（2026-10-20）：
  - [首页](https://elements.ai-sdk.dev/)，读了组件清单与页首的公告，页面后半没有读；
  - Chain of Thought 与 Task 两个组件的说明页。
- **shadcn/ui 的文档**（2026-10-20）：
  - [2026 年 6 月的聊天组件发布说明](https://ui.shadcn.com/docs/changelog/2026-06-chat-components)；
  - AI Elements 一节里的 Chat 页（Radix 版），只读了这一页，侧栏里其他组件的说明页没有读。
- **assistant-ui 的厂商文档**（2026-10-20）：只读了 ToolGroup 一页；关于只读显示，只看了检索结果的摘要。
- **本项目的源码：**
  - `apps/console/src/components/ai-elements/`：从 ai-elements 1.9.1 改写的六个展示部件，Apache 2.0；
  - `apps/console/src/session-view/`：现在的会话视图。
- 三家的源码都没有读。

## 看到的事实

- **现状（读源码）：**
  - 现在只用了消息、推理、工具、计划、终端与代码块这六个底层部件；
  - 每次工具调用默认展开，下面再有“工具输入”“结果数据”“输出正文”三层折叠；
  - 会话按页读取，每页 100 条，往上加载更早的页。
- **AI Elements（厂商自述）：**
  - 有 49 个组件。与会话有关的有：会话容器、消息、推理、工具、计划、任务、步骤链、队列、终端、代码块、文件树等。
  - 页首公告：AI Elements 正在并入 shadcn/ui，这个项目将于 2026 年 11 月底停止维护。
  - 步骤链（Chain of Thought）：可折叠的标题，下面是一串步骤，每步有标签、说明、图标与状态（完成、进行中、待做）。
  - 任务（Task）：可折叠的一组条目，标题为触发器，条目里可以放文件名的小标签。
  - 推断：这两个组件的属性都是普通的值，不依赖 AI SDK 的状态，可以只拿来显示。
- **shadcn/ui（厂商自述）：**
  - 2026 年 6 月发布五个聊天组件，其行为放在一个无界面的包里，有 Radix 与 Base UI 两个版本：
    - 消息滚动容器：处理锚定的回合、在前面插入的历史、跳到某条消息、滚动控制与可见性；
    - 消息：一行对话，支持把几条消息归成一组；
    - 气泡；
    - 附件；
    - 标记：一行状态、系统说明或带标签的分隔，可以用来显示工具活动。
  - 发布说明写明，这批组件不取代 AI Elements。
  - 文档里已有 AI Elements 一节，分 Radix、Base UI 与 Aria 三个版本，侧栏列着步骤链、推理、工具、任务、子代理、计划、队列、终端、文件树等组件。
  - 这几页都没有提到虚拟滚动，也没有写许可。
- **assistant-ui（厂商自述）：**
  - ToolGroup 把一个回合里相邻的工具调用收成一行，可以展开。
  - 收起时显示调用的个数与进行中的标记，静态版本还显示完成与失败的个数。
  - 它是带样式的组件，经 shadcn 的组件仓库分发。
  - 这个库围绕聊天的运行时（对话状态、输入框）组织；只读显示要把对话设成禁用。
- **推断：** 三家都没有现成的、按我们的事件形状把相邻工具调用归组的组件。怎样归组、组的摘要写什么，要我们自己写，这是一个很小的纯函数。

## 取了什么，没取什么

- **取：shadcn/ui 里的 AI Elements 一节（Radix 版），作为会话视图的组件来源。** 与控制台现有的 Tailwind、Radix、streamdown、shiki 是同一套。
  - 用消息滚动容器装整段会话，它对“在前面插入的历史”的处理正好对上我们往上加载更早页的做法；
  - 用标记显示一行一个的工具活动与分隔；
  - 用步骤链或任务把相邻的工具调用收成一行摘要；
  - 工具、终端与代码块只在展开时显示细节。
  - 现在从 ai-elements 1.9.1 改写来的六个部件，在同一批里换成这里的版本，不留两套。
  - 落在 ADR-024 的改写。加入依赖前核对许可。
- **取：把相邻的工具调用收成一行摘要这个做法。** 这是通用的做法，由我们按自己的事件形状实现。
- **没取：assistant-ui。** 它的价值在聊天的运行时，只读、按页显示的记录用不上；再与 AI Elements 混用，两套样式会打架。
- **没取：继续从原来的 AI Elements 项目取新组件。** 它将于 2026 年 11 月底停止维护。

## 时效

出现下面任何一种情况，这份记录就过时了：

- shadcn/ui 的 AI Elements 一节换了组件、样式或许可；
- 原项目停止维护的日期有变；
- 出现能直接按事件归组的工具调用组件。
