# 控制台交互与视觉修缮（规格）

状态：已在源码实现，未安装。用户于 2026-09-29 确认本规格；源码类型检查、单元测试与构建已通过，Host 已用独立合成预览完成首轮视觉检查；本次四项修正仍待 Host 复核。依据是用户对已安装 0.18.0 控制台的反馈，以及 Host 在 1024×768 与 1440×900、深色模式下对日常控制台的逐页检查。本文只改控制台前端（`apps/console`）的交互与视觉，不改后端契约。视觉约定仍以 [ADR-016](../decisions/016-human-console-design.md) 与 [buddy-settings.md](buddy-settings.md) 为准，本文与它们冲突处以本文为准。

## 原则

- 悬停只做轻量反馈（高亮、原生提示），不改变页面上的其他信息；信息区域只在点击或键盘选中后更新，避免画面跳变。
- 能用符号表达的按钮只放符号（×、›、▾ 等），说明放进提示和 `aria-label`，不在符号旁再写词语。
- 一个页面尽量只有一个主要滚动区域；辅助区域靠折叠而不是各自滚动。
- 深色模式以中性深灰为底，绿色只用于主要操作和当前选中。
- 状态用带文字的标记，不用只有颜色的符号。

## 修改项

### 全局

1. **名称**：页头显示 `Hey my buddy`，浏览器标签页标题为 `Hey my buddy · 本地工作台`（`apps/console/index.html`），页头品牌的 `aria-label` 同步。文档、包名与命令行仍用 `hey-my-buddy`。
2. **只有一个刷新**：右上角的全局刷新同时重新读取当前所有可见的数据源（控制台快照、工作目标列表、打开的时间轴、打开的委派详情及其协作记录、Buddy 配置的更新记录），可用一个共享的刷新信号让各数据钩子订阅实现。按下后图标转动，完成后在提示里显示"已刷新 · 时间"，失败时显示原因。图标换成通用的双箭头循环刷新图标。删除面板内的刷新按钮：工作目标列表的"刷新"、委派记录的"刷新记录"、协作记录的"刷新协作记录"、Buddy 配置更新记录的"刷新记录"；时间轴工具栏的"自动刷新 · 时间"移到全局刷新按钮的提示里。自动轮询保持不变。
3. **连接状态**：页头的"已连接"只在断开或重连时显示（带处理办法），正常时不显示。
4. **深色配色**：把画布、面板、分隔线、编辑态等从偏绿的深色改为中性深灰，例如 `--canvas #111315`、`--surface #181a1d`、`--subtle #202327`、`--line #2a2d31`、`--line-strong #3a3e44`、`--ink #e6e8ea`、`--muted #a3a8ae`、`--faint #868c93`、`--edit-surface #1c1f22`、`--edit-line #465059`、`--edit-wash #1a1d20`，以实际对比度调校。绿色（`--accent`）只留给主要按钮、当前导航项和当前选中项；`--accent-wash`、`--accent-soft` 相应改为接近中性的深色；焦点框（`--focus`）改为与绿色区分的中性高亮色。执行配置色（`--cfg-*`）与偏好色（`--pref-*`）保持可辨识。正文与背景对比度不低于 WCAG AA。浅色模式不改。

### 委派记录与时间轴

5. **悬停不改信息**：时间轴元素（执行片段、排队、路由、等待 Host、事件、验收标记、行标签）的 `onMouseEnter` 不再改变检查器内容和纵向参考线；只有点击、键盘聚焦移动或回车后才更新。悬停时元素自身高亮，并用原生提示显示简短信息。删除检查器里随悬停变化的"预览"行。
6. **视图切换**："以列表查看"改为分段控件"时间轴 | 列表"，当前视图高亮，不再出现切换后按钮文字不变的情况。
7. **收起列表后的小点**：删除收起栏底部只有颜色的状态点；收起栏只保留"工作目标 ›"。
8. **符号按钮去掉文字**：委派详情的"× 关闭详情"改为只有 × 的图标按钮；检查器的"收起/展开"改为 chevron 图标按钮；取消固定保留 ×。所有图标按钮都有 `aria-label` 与提示。
9. **减少滚动条**：
   - 目标标题区不再单独滚动：标题与描述一行，统计与"时间统计"合并为一行，其余折叠。
   - 委派卡片横排改为可换行的紧凑卡片，超过两行时折叠为"展开全部 N 个"。
   - 图例收进工具栏里的"图例"弹出层。
   - 检查器默认收起为一行摘要（当前选中项的类型、委派与时间），点击后展开为可调高度的抽屉，不再常驻占用时间轴下方空间。
   - 只保留时间轴自身的横向与纵向滚动；滚动条改细，不悬停时淡出。
10. **空闲折叠带**：竖排的"空闲 1 时 10 分 展开"改为折叠带上的一个小图标，悬停显示时长提示，点击展开。
11. **三栏区分**：打开委派详情形成三栏时，右侧详情使用与时间轴不同的底色（比 `--surface` 高一级），与中栏之间有明显分隔线或阴影；详情顶部的标题区固定，不随内容滚动。

### Buddy 配置

12. **删除档位上的菱形**：删除 `.effort-tag.override::after`。档位覆盖已由颜色、图标和描边表达；是否为覆盖、覆盖理由在档位菜单里显示。
13. **档位菜单**：
    - 单选项排成整齐的一列：单选框不继承全局输入框宽度（`width: auto`、不参与伸展），文字不换行成竖排，图标与文字对齐。
    - 已是 Router 的档位不显示"设为 Router"按钮，改为一行"当前 Router"状态；其他档位按现有规则显示按钮或禁用原因。
14. **Router 警告如实说明**：当前没有任何已验证的 Router 时，顶部状态行不再建议"在另一个具备 decision 能力的档位上设为 Router"，改为"暂无已验证的 Router，默认路由会停在 Host 边界；委派时请指定配置"，详情里说明原因。只有确实存在其他可用 Router 时才建议切换。
15. **模型列表默认更紧凑**：没有任何已启用档位的 harness 分组默认折叠，分组标题显示已启用数与总数；"只看已启用"筛选保持现有默认。

### 设置

16. **设置页重做**：内容区限制最大宽度并与页头对齐，使用统一的分组卡片（标题、说明、控件），分组间距一致：
    - "显示"：主题用分段控件（浅色 / 深色 / 跟随系统），当前选项高亮。
    - "存储"：显示占用概览（总占用、可回收），"检查占用 / 生成计划 / 确认回收"的流程与功能不变。
    - 为以后的语言设置预留同样格式的分组位置，但不显示空分组。

## 验收

- `apps/console` 下 `tsc --noEmit`、`vitest run` 全部通过；为 2、5、6、7、8、13、14、15、16 补测试或更新现有测试（包括去掉悬停预览后原有的检查器预览测试）。
- `vite build` 重新构建 `src/buddy/console_assets` 并提交，产物可由源码重现。
- 使用 `tests/probes/objective_console_preview.py` 的合成数据，在深色与浅色、1440×900 与 1024×768、390×844 窄屏下检查：时间轴页只有时间轴自身的滚动条；悬停不改变检查器；刷新有反馈；三栏可区分；设置页与档位菜单对齐。不连接日常控制台。
- 不引入新的运行时依赖；不留下任何后台进程。
