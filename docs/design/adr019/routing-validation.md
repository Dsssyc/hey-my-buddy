# Routing validation and quota recovery

This ADR-019 second-stage slice follows the 0.24.0 private-directory prerequisite. Account login, credentials and account-source separation remain outside this slice. Schema stays 15; existing review certificates and native exhaustion records continue to use `meta`.

## Retained review diagnostics

The native controller first retains the actual `config/read` and `thread/start` policy responses in its private result, including a response that fails the policy gate. It still stops before model input when native permissions are not acknowledged. The review-check adapter evaluates the nine existing checks and publishes `review-evidence.json` in its outer attempt directory before removing the private controller/fixture tree. Publication uses an exclusive ordinary-file write with the decision-11 ancestor/link checks. Failure to retain evidence fails certification and preserves the private diagnostic tree, even when stop is confirmed; unknown stop also preserves it.

The retained format `buddy-review-evidence-v1` records selected policy enums and booleans, whether model/provider/cwd match, fixed path aliases, counts of unexpected policy entries, correlated event aliases, recognized test-operation names, response-envelope shape, exit codes, byte counts, denial/marker comparisons, usage and the exact boolean basis of each check. Native command text, tool output, prompts, responses, unknown field names/values and account/config secrets are omitted. The source projection owns every output key; there is no generic redactor or pass-through native object. Raw native traces remain private and disappear only after affirmative native/controller stop evidence and successful diagnostic publication.

Codex 0.159.0 returned the requested policy alongside extra native default metadata. Native admission already required recursive agreement on requested controls, while the old evaluator required whole-object equality for features, shell policy and network. Both now use the same strict typed requested-control comparison; filesystem grants remain exact after removing null metadata, extended profiles and MCP servers remain forbidden, and the thread's active profile/sandbox/model/provider/cwd still require their native acknowledgements. The observed code-mode call omitted `max_output_tokens` and returned two `input_text` blocks: fixed bridge metadata followed by one JSON command-result envelope. The parser accepts that exact bounded shape, the same declared variable in `text(...)`, an optional output limit and one exact test command; unrelated JS, extra calls, mismatched replies, arbitrary prose and incomplete/truncated evidence continue to fail closed.

`review-evidence.json` is an explicit addition to the attempt evidence whitelist. Its canonical byte hash is returned as `evidenceSha256`, and `evidenceFile` identifies the retained filename. Worker receipts advertise this actual diagnostic in `logPaths.reviewEvidence`, instead of reporting deleted private controller logs. Health retains its filename/hash alongside run and attempt identity. The diagnostic assists investigation; certification still requires native policy, operation correlation, boundary denials, unchanged fixtures, budget and shutdown evidence.

## No-reset exhaustion recovery

A blocked provider/limit retains its exhaustion until the recorded reset or a newer available native observation. No-reset records project a single-use chance one hour after the blocking observation or last consumption; unknown/partial observations neither clear it nor reset the consumed marker. Candidate inspection remains provisional. Adopting the selected configuration claims all applicable open provider/limit chances in the same write transaction; another decision rechecks the marker, and unchosen providers keep their chances. Explicit Host configurations continue to dispatch with quota warnings.

`quota-redetect` opens one chance early for the requested harness/provider and performs no query or model call. Its requestId-bound command receipt, event and marker update commit atomically, so a lost reply replayed after consumption cannot reopen the chance. A fresh explicit request may reopen it. Existing pre-meta native display evidence is imported only during a write action with monotone observation checks. Health/model profiles expose bounded nonsecret recovery facts; the separate QuotaRecovery component adds an entry inside harness details and keeps the request identity in tab session storage through uncertain replies.
