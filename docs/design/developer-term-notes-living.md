# 用词清单：拿不准的“用户 / user”

本次把记录里指开发者的“用户”改成“开发者”时，拿不准、因此**没有改**的地方（倾向写“开发者”的，是按复合词规则或公开文档口径保留的，供 Host 定夺）。每行：文件、行号、那一句、倾向哪个词与原因。Host 读过之后删除本文件。

- README.md:37 — “Installing or upgrading the daily service needs the user's separate authorization.” — 倾向：用户 — 原因：与中文版同一句产品规则。
- README.md:85 — “For user-authorized long tasks, `"timeoutSeconds": 0` explicitly removes the execution deadline” — 倾向：用户 — 原因：与中文版同一句产品行为。
