上一轮任务页、微任务详情、时间轴、Buddy 页与设置页的稿已在实现并验收之后删除（2026-10-17），要看可以到 git 的历史里找。颜色、记号与版式的规则写在 `base.css` 里，含义见执行计划的"设计"一节。页面实现并验收之后，对应的稿删除。

批次三的实际应用图为 `batch3-before-{macro,detail}-{1280,390}-{light,dark}.png`、对应的 `batch3-after-*`、`batch3-after-lanes-*` 与 `batch3-delete-{confirm,blocked}-{1280,320}-{light,dark}.png`；这些区别于下述静态稿的编造画面，仍只使用私有合成数据。Lead 在整合检出完成 1050 项前端、385 项浏览器及 250 项受影响 Python 检查，名下 8 项已接受；整批的 Host 验收与安装仍未进行，详情见 [Lead 交接](../console-batch3-lead-notes.md)。

批次三的两份稿共用 `batch3.css`，在浏览器里直接打开，随窗口宽度变化；在地址后加 `?theme=dark` 或在 `<html>` 上加 `data-theme="dark"` 看深色。数据、会话编号、用量与检查结果均为编造。详情稿可点击顶部时间片切换示例内容，首次打开只居中一次；右下角的缩小、放大、适合宽度可以操作，顺序与应用现有控件一致，缩放保留所选段的锚点，适合宽度显示整个微任务。时间片行下不再有重复读数。

泳道稿用 24 px 的组间空白、整体的 surface 底色和 2 px 的粗顶线区分泳道，普通微任务留在 paper 底色上。Lead 自己那一行就是组头，包含收起箭头、Lead 记号、任务名、自己的时间片与右侧唯一的汇总；汇总的用量写明 token。收起只隐藏名下的行，Lead 的行与汇总保留。第二条默认收起，可以分别展开；没有额外的组名或底部汇总。窄屏把名字放在自己的轨道上方，共用横向滚动与刻度，Lead 行的名字与汇总在同一块内换行。

历史执行条使用产品现有的六种低饱和色，按完整的 harness、提供方、模型、推理强度四段 buddy 分配，样例里同一个模型的 max、high 与 medium 各有自己的颜色；颜色次序按宏任务里第一次出现的先后。微任务条目和泳道行显示原样的 harness 图标、模型与推理强度，悬停或键盘聚焦名称旁的 buddy 可看完整四段。图标内嵌自当前锁定的 `@lobehub/icons-static-svg` 1.95.1，与 Buddy 页使用相同的 `codex-color.svg` 与 `claudecode-color.svg`，没有改图形。宏任务时间轴顶部的缩放、微任务名字切换等其余控件仅表示位置；静态稿不调用 API、不读取看板、不代表功能已经实现。
