# 控制台的静态稿

[执行计划](../console-frontend.md)的设计依据：每个页面一份静态稿，用浏览器直接打开 HTML 文件即可。数据是编的，稿不联网，也不是实现。在 `<html>` 上加 `data-theme="dark"` 看深色。

| 文件 | 内容 | 状态 |
| --- | --- | --- |
| `tasks.html` | 任务页：宏任务的列表、一个宏任务及其时间轴、选中的微任务 | 方向已由用户认可 |
| `task.html` | 微任务的详情：等待验收的微任务，选中第二个回合；右栏是这个回合的过程：Worker 一块里是会话的内容，末尾是产物 | 已由用户认可 |
| `task-wide.html` | 微任务的详情：宏任务的列表收起之后的样子 | 已由用户认可 |
| `task-live.html` | 微任务的详情：进行中的回合，右栏是 Worker 的会话，底部是当前的阶段 | 已由用户认可 |
| `task-router.html` | 微任务的详情：选中路由一步，右栏是 Router 的过程与它的选择 | 已由用户认可 |
| `task-accepted.html` | 微任务的详情：已验收的微任务，选中验收一步 | 已由用户认可 |
| `buddies.html` | Buddy 页的目录，模型一项：一行一个模型，第四列的每个档位是一个 buddy；右边是档位与模型的设置 | 已由用户认可 |
| `buddies-harness.html` | Buddy 页的目录，Harness 一项：一行一个 Harness；右边是它的位置、账户与额度 | 已由用户认可 |
| `roles.html` | Buddy 页的角色：Router 的列表、设置与记录 | 待确认 |
| `settings.html` | 设置页 | 待确认 |

颜色、记号与版式的规则写在 `base.css` 里，含义见执行计划的"设计"一节。页面实现并验收之后，对应的稿删除。

各份稿共用一个 `base.css`，类名很短，后加的规则曾经三次撞上 `buddies.html` 里已有的类名（`.grp`、`.fold`、`.n`），把那份稿的表头与收起的一行画坏而没有被发现；2026-10-11 已改名修好，并把全部十份稿重新截图看过。改 `base.css` 之后要把每一份稿都重新打开看一遍，不只看正在改的那一份。稿里有几处 13px 与 11px 的字，实现时按执行计划归到四档字号。
