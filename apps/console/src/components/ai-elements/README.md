# AI Elements display subset

These components adapt the display portions of Vercel AI Elements `ai-elements@1.9.1` (`vercel/ai-elements`), under the Apache License 2.0 in [LICENSE](LICENSE). The source files were `message.tsx`, `reasoning.tsx`, `tool.tsx`, `plan.tsx`, `terminal.tsx`, and `code-block.tsx`; source SHA-256 values, respectively, are `19c7755740e116f221e4247f7b6d4f20b57a44e4c4fcf66d2db5e1f111476509`, `f138cddde35854f73632ff51d48230f8d6e16e0a49a74b44a93b51993a65550e`, `5b520e0c33792cba0ceb04e1cb18c69b212cffacdb52d7297e292c7af568dda4`, `bfa20e90199fa40e5f714be131798406dc07b23051f8c48c590e91c65ade99d8`, `04b9b534925054cfe67fdc3bc212eb7261b4912e6e970c4844a195907d3a9a93`, and `5c7285171c5aa741749a1642a85f492a9b5e80dc4ccb704b5c3f58c45efebd04`.

The adaptation keeps message layout, Streamdown Markdown, Radix disclosures, ANSI output, and Shiki highlighting. It removes AI SDK state, branches, inputs, model controls, automatic streaming behavior, and fixed dark terminal colours. The caller supplies displayed labels through i18n. Markdown skips raw HTML, permits only public HTTP(S) links, suppresses images, and puts fenced code behind a disclosure with copy. Terminal ANSI text never produces links; its CommonJS package uses the narrow `ansi.cjs` export adapter. CodeBlock mounts only when its disclosure is open, then imports Shiki core, the two themes, and the requested supported grammar. Unknown languages stay plain text; a failed highlighter shows a visible error and the original code.
