# Domain language

| Term | Meaning |
| --- | --- |
| 工作目标 / objective | A user's overall objective used to group related delegations for browsing and archival. It does not schedule work or grant control authority. |
| 委派 / governed goal | One bounded piece of work owned and accepted by a Host; it may span several Worker turns. |
| 协助任务 / helper | A delegation explicitly authorized by the Host to help another delegation. |
| 执行回合 / turn | One Worker execution ending in a result, assistance request or attention boundary. |
| 验收 / acceptance | The Host's evidence-backed judgment on a fixed artifact, separate from Worker completion. |
